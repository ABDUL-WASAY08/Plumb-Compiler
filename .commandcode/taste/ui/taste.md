# UI & Design Taste

- Prefers UI color themes that avoid blue entirely, favoring neutral zinc/slate backgrounds with emerald green accents (success/primary states) and amber warning pills, plus zinc-bordered cards. Confidence: 0.7
- Expects polished, "ultra-clean" visual quality: consistent 8px/16px spacing grid, precise padding, clear component hierarchy, and distinct interactive states (hover effects, cursor pointers, tooltips). Confidence: 0.7
- Wants subtle drop-shadows and neat borders with sharp alignment rather than heavy or loose styling. Confidence: 0.6
